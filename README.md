## Project Overview

Antenati ToolKit Pro helps genealogists and family historians investigate Italian Antenati archive material. It is intended for research that connects people, locations, records, and family relationships across historical sources.

The application runs on the web, allowing researchers to work through a compatible browser rather than relying on one particular desktop operating system. Version 3 is the current release profile for users seeking a dedicated workspace for Italian genealogy research.

## Research Workflow

A normal session may follow these steps:

1. Launch Antenati ToolKit Pro in a web browser.
2. Choose the family-history question, individual, or genealogical line to examine.
3. Research the related material in the Italian Antenati archives with the toolkit open.
4. Capture relevant observations about the people, places, and relationships under review.
5. Revisit the gathered information and extend the investigation when necessary.

The application supports the research process, but findings should be verified against the archival sources themselves.
